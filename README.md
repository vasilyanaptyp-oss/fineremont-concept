# fineremont-concept

Концепт головної сторінки для ТОВ «Файний Ремонт» (Київ).

Увесь контент, фото, відгуки та контакти взяті з чинного сайту
https://fineremont.kiev.ua/ . На чинному сайті нічого не змінено.

Сторінка позначена `noindex,nofollow` — вона не має конкурувати з fineremont.kiev.ua у пошуку.

Статичний HTML + CSS + JS. Анімації: GSAP 3 + ScrollTrigger з CDN. Без збірки.
Папка `_src/` — вихідні матеріали (оригінальні фото, тексти), на GitHub не публікується.
